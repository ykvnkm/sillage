# sillage

> _Sillage_ — шлейф, след аромата в воздухе. Заодно метафора: молекулярный след,
> который тянется до человеческого восприятия.

Открытая система, связывающая три уровня парфюмерии, которые обычно живут
порознь: **молекула → смесь → человеческое восприятие**.

**Статус: Фаза 0 (скелет репозитория). ML-кода пока нет.**

## Архитектура

Пять слоёв, каждый самодостаточен и имеет собственные метрики:

```
L4  Продукт        API + карта запахов + рекомендер + детектор клонов
L3  Восприятие     ABSA по отзывам: стойкость, шлейф, сезон, "пахнет как"
L2  Мост           нота ↔ парфюмерный материал ↔ молекула (entity linking)
L1  Смеси          агрегация молекулярных эмбеддингов → профиль/расстояние
L0  Молекулы       GNN structure→odor, multilabel, 135 дескрипторов
```

Слои развязаны намеренно: если самый рискованный L2 не взлетит, рабочими
остаются L0, L1 и продукт поверх нот без молекул.

## Data provenance

Раздел будет заполнен на шаге 0.5. Ключевое правило проекта: **сырые данные
не попадают в репозиторий.** В git лежат только скрипты загрузки и контрольные
суммы; публикуются исключительно производные артефакты (веса, эмбеддинги,
агрегаты) с явным указанием источника и условий использования.
