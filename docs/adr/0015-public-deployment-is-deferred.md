# ADR-0015. Публичный деплой отложен; сервис запускается локально

- **Дата:** 2026-10-11
- **Статус:** принято
- **Фаза:** 2, шаг 2.6
- **Отменяет:** пункт 6 [ADR-0014](0014-model-weights-live-on-the-hub-pinned-by-checksum.md)

## Контекст

Деплой на HF Spaces был готов и упал при первом запуске: `402 Payment Required` на
создании Space. В июле 2026 Hugging Face перевёл Docker- и Gradio-Spaces на CPU в
платные (подписка PRO, $9 в месяц); бесплатными остались только статические.

Проверены альтернативы. Koyeb закрыл бесплатный план для новых аккаунтов в феврале
2026. Render бесплатно даёт 512 МБ и 0.1 CPU; сервис туда помещается — измерено под
теми же ограничениями: 274 МБ памяти, старт 63 секунды, проходит smoke-тест.
Google Cloud Run бесплатен в пределах квоты, но требует карту и заметно больше
настройки.

## Решение

Публичного адреса пока нет. Сервис запускается локально одной командой
(`docker build` + `docker run`, инструкция в README); образ сам скачивает модель,
закреплённую в `deploy/hub.json`.

Задача `deploy` и `scripts/deploy_space.py` удалены, а не закомментированы: код,
который никто не запускает, перестаёт работать незаметно. Остаётся всё, что ценно и
без хостинга:

- модель на HF Hub с закреплённой ревизией и sha256 (хранение моделей бесплатно);
- задача `image` в CI: сборка образа и smoke-тест на каждом PR;
- `scripts/smoke_test.py`, которым проверяется и будущий публичный адрес.

## Почему отложено, а не сделано на Render

Сейчас ссылку некому открывать: без поиска по названию (шаг 2.7) сервисом пользуются
только те, кто пишет SMILES. Хостинг с засыпанием и минутным стартом — цена, которую
стоит платить, когда появятся пользователи. Вернуться к решению после шага 2.7.
Кандидат по умолчанию — Render: бесплатно, без карты, сервис помещается.

## Последствия

Шаги 2.8 (карта запахов) и 2.9 (наблюдаемость) не зависят от публичного адреса и идут
по плану. Дашборд дрифта на 2.9 будет наполняться локальным трафиком, пока нет
публичного.
