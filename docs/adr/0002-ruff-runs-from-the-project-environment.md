# ADR-0002. Ruff в pre-commit запускается из окружения проекта, а не из upstream-зеркала

- **Дата:** 2026-08-11
- **Статус:** принято
- **Фаза:** 0, шаг 0.3

## Контекст

Стандартный способ подключить ruff к `pre-commit` — указать upstream-репозиторий
`astral-sh/ruff-pre-commit` с полем `rev`. Тогда `pre-commit` создаёт для хука
собственное изолированное окружение и ставит туда ruff версии из `rev`.

При этом ruff уже присутствует в проекте как dev-зависимость, зафиксированная в
`uv.lock`. Возникают два независимых источника версии.

Ruff меняет правила форматирования между релизами. Расхождение версий даёт
худший из возможных классов ошибок: локальный коммит проходит, а CI краснеет на
форматировании — или наоборот. Диагностируется это долго, потому что оба
инструмента называются одинаково и оба «есть».

## Решение

Ruff подключается через `repo: local` с `language: system` и командой
`uv run ruff`. Хук исполняет ровно тот бинарник, который зафиксирован в
`uv.lock`. Источник версии остаётся один.

Универсальные файловые проверки (`check-added-large-files`, `detect-private-key`,
`end-of-file-fixer` и прочие) по-прежнему берутся из upstream-репозитория
`pre-commit/pre-commit-hooks`, закреплённого по `rev`: у них нет аналога внутри
проекта, дублирования версий не возникает.

## Последствия

**Положительные.** Локальный хук и CI не могут разойтись по версии ruff.
Обновление ruff — одно изменение в `uv.lock`, а не два в разных файлах.
Хук не тратит время на сборку отдельного окружения.

**Отрицательные.** Хук требует наличия `uv` в `PATH`, то есть перестаёт быть
самодостаточным. Для этого проекта приемлемо: `uv` и так единственное требование
для сборки, что зафиксировано в README.

`language: system` означает, что `pre-commit` не управляет окружением хука и
целиком доверяет команде. Ответственность за воспроизводимость переходит к
`uv.lock` — там, где она и должна быть.

## Альтернативы

- **Upstream `ruff-pre-commit` + ручная синхронизация `rev` с `uv.lock`.**
  Отклонено: синхронизация вручную рано или поздно не выполняется.
- **Не запускать ruff в pre-commit, полагаться только на CI.** Отклонено:
  цикл обратной связи вырастает с миллисекунд до минут, история засоряется
  коммитами «fix lint».
