# ADR-0005. Блокноты хранятся в git вместе с выводом

- **Дата:** 2026-08-11
- **Статус:** принято
- **Фаза:** 1, шаг 1.1

## Контекст

`.ipynb` — это JSON, в котором рядом с кодом лежит весь вывод: таблицы, счётчики
выполнения и изображения в виде base64. Один график — сотни килобайт текста.
Перезапуск блокнота без единой правки кода меняет файл целиком.

Стандартное решение — вырезать вывод перед коммитом (`nbstripout`). Оно даёт
читаемые диффы и здоровую историю, но убивает главное свойство блокнота как
портфолио-артефакта: открыл ссылку на GitHub и сразу увидел анализ с графиками.

Проект существует в том числе как демонстрационный. Исследовательская часть,
которую нельзя посмотреть по ссылке, теряет значительную долю смысла.

## Решение

**Вывод сохраняется в git.** Блокноты в `notebooks/` коммитятся вместе с
таблицами и графиками и предназначены для чтения как готовый материал.

Издержки снимаются тремя мерами вместо стриппинга:

1. `nbstripout --keep-output` — вырезаются счётчики выполнения, пути к ядру и
   служебные метаданные, вывод остаётся. Основной источник шума в диффах — не
   картинки, а перенумерация ячеек при каждом перезапуске.
2. Отдельный лимит размера: обычные файлы 1 МБ, `*.ipynb` — 2 МБ. Порог остаётся
   осмысленным и ловит случайно напечатанный целиком датафрейм.
3. Дисциплина: `df.head(20)` вместо `df`, разумные размеры фигур.

Ruff проверяет и форматирует код внутри блокнотов наравне с `.py`. Исключение
`E402` (импорты не в начале файла): в блокноте раздел, начинающийся со своих
импортов, читается лучше, чем один общий блок наверху.

## Последствия

**Положительные.** Анализ виден по ссылке без запуска. Диффы остаются
обозримыми: без счётчиков выполнения меняются только реально изменившиеся ячейки.

**Отрицательные.** История репозитория растёт быстрее, чем при стриппинге.
Дифф по перерисованному графику остаётся нечитаемым — меняется base64-блоб;
смотреть придётся на отрендеренную версию, а не на дифф.

Порог в 2 МБ рано или поздно будет достигнут. Тогда решение — не поднимать
порог, а разделить блокнот или вынести тяжёлые изображения.

## Альтернативы

- **`nbstripout` без `--keep-output`.** Отклонено: убивает демонстрационную
  ценность, ради которой блокноты и ведутся.
- **jupytext: коммитить только парный `.py`.** Отклонено по той же причине;
  идеальные диффы не компенсируют отсутствие отрендеренного результата.
- **Не проверять блокноты линтером.** Отклонено: код в блокноте — тоже код,
  и читать его будут внимательнее прочего.
