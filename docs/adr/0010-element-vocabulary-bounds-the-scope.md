# ADR-0010. Словарь элементов входит в область определения

- **Дата:** 2026-10-11
- **Статус:** принято
- **Фаза:** 2, шаг 2.1

## Контекст

Демонстрация модели на незнакомых молекулах показала случай, который объявленная
область определения ([ADR-0009](0009-training-distribution-matches-the-declared-scope.md))
не поймала.

Бромстирол `BrC=Cc1ccccc1` — однокомпонентная нейтральная органика массой 183 Da,
то есть по всем действующим правилам законный вход. Модель выдала на него
`sulfurous`, `onion`, `garlic` с уверенностью 1.00; эксперты описали эту молекулу
как `green`, `hyacinth`, `leafy`. Промах в противоположную сторону при максимальной
уверенности.

Проверка состава обучающих данных дала причину:

| Элемент | Молекул в обучении |
| --- | --- |
| C | 3805 |
| O | 3316 |
| S | 551 |
| N | 440 |
| P | 2 |
| Cl | 1 |
| F | 1 |

**Брома в обучающих данных нет вообще.** Это не «мало примеров» — это отсутствие
информации о вкладе брома где-либо в модели. Любой её ответ про бромсодержащую
молекулу является экстраполяцией по определению, а не ошибкой оценки.

## Решение

`ChemicalScope` получает поле `allowed_elements` — элементы, встречающиеся хотя бы
в `min_molecules=5` обучающих молекулах. Молекула с элементом вне словаря
отклоняется с указанием конкретного элемента.

Словарь — свойство обученной модели, а не химии, поэтому он выводится из обучающих
данных и сохраняется внутри артефакта (`card.scope`), а не задаётся константой.
Обучение идёт в два прохода: сначала правила, не зависящие от данных, затем
словарь по тому, что осталось, затем фильтр по словарю.

Для текущего артефакта словарь получился `('C', 'N', 'O', 'S')`.

## Обоснование

Измерено на тестовой части, 485 молекул:

| | вне словаря | внутри |
| --- | --- | --- |
| молекул | 2 (0.4%) | 483 |
| средняя AP на молекулу | **0.270** | 0.562 |
| уверенных предсказаний (>0.9) на молекулу | **3.5** | 0.2 |

Семнадцатикратная разница по числу уверенных предсказаний — это и есть искомая
патология: модель максимально уверена именно там, где у неё меньше всего оснований.
У бромстирола AP 0.061 и 7 уверенных предсказаний.

**Чем это отличается от провалившейся попытки в [E-008](../journal/experiments.md).**
Там отказ строился на расстоянии: сходство Танимото с ближайшей обучающей молекулой,
и результат оказался неотличим от случайного отказа. Здесь проверяется не
расстояние, а **словарь**: про бром модель знает не «мало», а ничего. Поэтому
правило даёт логическую гарантию, а не статистическую корреляцию.

Порог 5 молекул выбран по данным: фосфор встречается в 2 молекулах, хлор и фтор — в
одной каждый. Это присутствие без сигнала, и хлорсодержащая молекула теста
действительно предсказывается хуже среднего (AP 0.480 против 0.562). Порог проходит
выше них.

## Последствия

**Положительные.** Класс отказов «уверенная чушь на незнакомой химии» закрыт
детерминированным, объяснимым правилом. Пользователь получает не молчание, а
причину: «содержит Br, которого не было в обучении». Цена — 0.4% покрытия.

**Отрицательные.** Словарь узкий: `C, N, O, S`. Любая галогенированная молекула
отклоняется, хотя галогенированные душистые вещества существуют. Это честное
отражение данных, а не ограничение по существу; расширение требует данных, а не
правки порога.

**Что это не исправляет.** Уверенные ошибки на молекулах **внутри** словаря.
Пример из той же демонстрации: `CCC(C)CN1CCCC1` получает `animal` с уверенностью
1.00 при настоящих `metallic, oily, roasted`. Азотистые соединения действительно
часто пахнут животным, то есть догадка химически осмысленная, но неверная. Такие
случаи словарём не ловятся и остаются задачей калибровки и оценки неопределённости
(шаг 2.2).

## Альтернативы

- **Расширить область по массе и зарядам.** Отклонено: бромстирол проходит все эти
  правила, причина не в них.
- **Отказ по сходству Танимото.** Отклонено ранее и измеренно: неотличимо от
  случайного отказа (E-008).
- **Оставить как есть и полагаться на калибровку.** Отклонено: калибровка
  настраивается на валидационных данных того же распределения и систематически не
  исправляет переуверенность вне распределения.
