# Дорожная карта: продукт первым

Принято 11 октября 2026. Заменяет порядок шагов внутри Фаз 2–3 из `CONCEPT.md`;
состав слоёв L0–L4 и сами фазы не меняются.

## Причина пересмотра

Фаза 1 дала работающую модель: macro AP 0.342 против пола 0.035, в 9.8 раза выше
случайного; на незнакомых структурных каркасах — в 8 раз. При этом использовать её
невозможно: модель нигде не сохранена, не отдаёт предсказаний и не имеет интерфейса.

Одновременно четыре находки Фазы 1 остались незакрытыми — не решениями, а записями
в журнале. Продукт превращает их в блокеры: сервис обязан отвечать на любой ввод,
обязан честно показывать уверенность и обязан иметь model card с осмысленными
числами. Поэтому порядок меняется: сначала работающий публичный сервис, и каждая
исследовательская задача решается в тот момент, когда продукт в неё упирается.

## Шаги

Каждый шаг заканчивается чем-то, что можно показать.

| Шаг | Что делаем | Результат | Блокер, который закрывает |
| --- | --- | --- | --- |
| **2.1** | артефакт модели: обучение, сохранение, загрузка, model card | модель живёт в файле, а не в скрипте | — |
| **2.2** | калибровка вероятностей по каждой метке | 0.9 означает «в 90% случаев прав» | «модель не умеет говорить "не знаю"» |
| **2.3** | сценарий предсказания: SMILES → профиль + уверенность + похожие молекулы | функция, готовая к вызову из API | судьба 108 солей (решается через область определения) |
| **2.4** | FastAPI + Dockerfile, инференс на CPU | локальный сервис | — |
| **2.5** | веб-интерфейс: ввод, профиль, картинка молекулы, соседи | можно пользоваться с экрана | — |
| **2.6** | деплой на HF Spaces | **публичная ссылка** | — |
| **2.7** | имена молекул через PubChem, поиск по названию | **им могут пользоваться не-химики** | — |
| **2.8** | карта запахов: UMAP по эмбеддингам, интерактив | фишка из CONCEPT | — |

Шаг 2.6 — первый момент, когда проект существует для внешнего человека.
Шаг 2.7 — первый момент, когда он полезен тому, кто не пишет SMILES: парфюмеру,
студенту, любителю. До него продукт обслуживает только химиков.

## Исследования, идущие параллельно

Не «когда-нибудь», а привязанно к шагам продукта.

| Задача | Когда | Зачем именно тогда |
| --- | --- | --- |
| калибровка по меткам | шаг 2.2 | интерфейс обязан показывать честную уверенность |
| потолок согласия разметчиков (Goodscents против Leffingwell) | после 2.6 | в model card нужно «взято N% достижимого», а не голое число |
| GNN как другое представление | после 2.6 | плато 0.34 упирается в представление (журнал E-006); продукт к этому моменту уже работает и получит улучшение бесплатно |
| восстановимость стереохимии (Pyrfume, PubChem) | вместе с 2.7 | там же идёт работа с PubChem, запрос почти тот же |
| ms-pred как образец тренировочных конфигов | перед GNN | один вечер чтения, не внедрение |

## Что остаётся из принципов

Без изменений: бейзлайн раньше модели; ни одна модель не считается рабочей без
сравнения с бейзлайном на идентичном сплите; accuracy запрещена; сырые данные не
в git; каждое архитектурное решение — в `docs/adr/`; дневник экспериментов ведётся,
включая неудачи.

Отменено: ритуал закрытия фазы устными ответами на вопросы.
