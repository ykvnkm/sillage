# Model card: odor-ensemble-v3

Автоматически сгенерировано `scripts/train_model.py`. Не редактировать руками —
правки перезапишутся при следующем обучении. Время обучения сюда намеренно не
пишется (оно есть в `card.json` рядом с весами): иначе переобучение той же модели с
тем же сидом меняло бы этот файл, и в истории git появлялись бы пустые правки.

## Что эта модель делает

По структуре молекулы предсказывает, какие из 138 ольфакторных дескрипторов
ей свойственны. Выход — 138 независимых оценок; по 137 из них это
откалиброванные вероятности (раздел «Калибровка»), по остальным — только порядок.

## Область определения

Модель определена на **однокомпонентных нейтральных органических молекулах**
массой 30–400 Da, состоящих только из элементов
C, N, O, S. Сама модель вне области не отказывается — отказывает сценарий
`PredictOdor` до её вызова, так что числа о молекуле вне области не возникает вообще.

Основание: на входах вне области модель выдаёт уверенные и неверные ответы. Карбонат
магния получает 1.000 за семь дескрипторов и 0.000 за свою единственную метку
`odorless`. Вне области определения молекула примерно в шесть раз чаще оказывается
катастрофической ошибкой. Подробности — журнал E-007 и E-008.

## Качество

Рядом с каждой метрикой — **пол**: что показывает предсказатель, который не видел ни
одной молекулы и знает только частоты дескрипторов. Без пола эти числа нечитаемы:
micro AUC начинается с 0.78 просто от ранжирования частых дескрипторов выше редких.

| Метрика | Модель | Пол | Во сколько раз выше |
| --- | --- | --- | --- |
| macro AP | **0.4018** | 0.0382 | ×10.5 |
| macro AUC | 0.8879 | 0.5000 | — |
| micro AP | 0.5050 | 0.1717 | ×2.9 |
| micro AUC | 0.9309 | 0.7832 | — |
| macro AP, консенсус экспертов (26 нот) | **0.6163** | 0.0664 | — |

Измерено по 116 из 138 дескрипторов. Основная метрика
проекта — **macro AP**: только у неё пол честно низкий.

## Калибровка

Выход **откалиброван** по каждой метке: Platt scaling на предсказаниях для молекул,
которых модель при обучении не видела
([ADR-0011](../adr/0011-calibration-is-per-label-and-refuses-weak-labels.md)).
Откалибровано 137 меток из 138. Для остальных (1)
слишком мало примеров: по ним выдаётся не вероятность, а только порядок, и продукт
показывает пометку «без проверки».

Проверено на тестовом сплите: в диапазоне 0.85–1.00 модель обещает 0.902 и оказывается права в 0.851 случаев (104 пар «молекула–нота»).

Сто пар — мало, чтобы отличить разрыв от случайности. На 852 парах перекрёстной проверки (молекулы, которых не видели ни модель, ни калибратор) та же полоса обещает 0.902 и сбывается в 0.890 случаев; разрыв с вероятностью 95% лежит между -0.8 и +3.1 п.п. (журнал E-023, `results/reliability_odor-ensemble-v3.csv`).

## Потолок: насколько согласны сами эксперты

Метки обучения взяты из двух независимых экспертных баз, Goodscents и Leffingwell.
На 247 молекулах, описанных обеими и не виденных моделью ни при обучении,
ни при калибровке, по 49 нотам с достаточным числом примеров
(каппа Коэна: 0 — случайное совпадение, 1 — полное):

| Кто с кем | Каппа |
| --- | --- |
| эксперты Goodscents ↔ эксперты Leffingwell | **0.45** |
| модель ↔ Leffingwell | 0.35 |
| модель ↔ Goodscents | 0.31 |

Модель согласна с одной базой примерно на 77% того, насколько с ней согласна
другая база экспертов. По отдельным нотам качество модели следует за согласием
экспертов (ранговая корреляция 0.45): где эксперты расходятся, модели не на
что опереться. Подробности — журнал E-018, `results/annotator_ceiling_odor-ensemble-v3.csv`.

## Известные ограничения

1. **По 1 дескрипторам вероятности нет** — только ранжирование.
2. **Разница между стереоизомерами ненадёжна.** Графовые сети видят R/S и E/Z и
   дают изомерам разные ответы, но в паре изомеров, которых эксперты описали
   по-разному, модель отдаёт ноту нужному в 52–57% случаев. Это предел данных,
   а не модели: вторая база экспертов на тех же парах угадывает первую в 53%
   случаев (журнал E-020). Продукт показывает это предупреждение при каждом
   вводе со стереохимией.
3. **Разметка субъективна.** Дескрипторы — мнение экспертов, не измерение, и на
   расплывчатых словах (`fresh`, `sweet`, `warm`, `sharp`) эксперты двух баз
   согласны друг с другом слабо. Там слабее и модель.
4. **«Во сколько раз лучше случайного» обманчиво для частых нот.** Этот множитель
   ограничен сверху единицей, делённой на частоту ноты: у `fruity`, которая есть у
   40% молекул, он не может превысить 2.5 даже при безошибочном ответе. Сравнивать
   ноты по нему нельзя; по AP и по согласию экспертов — можно.
