# sillage

Предсказывает запах молекулы по её структуре и говорит, насколько уверен: словами,
точность которых измерена на молекулах, которых модель не видела. Отказывается
отвечать там, где не обучалась, и объясняет почему.

Код, журнал экспериментов и model card: [github.com/ykvnkm/sillage](https://github.com/ykvnkm/sillage).

Этот Space собирается автоматически из `main` после того, как тесты и проверка
образа прошли. Не редактируйте файлы здесь: следующий деплой их перезапишет.
